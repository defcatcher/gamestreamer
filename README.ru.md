<h1 align="center">GameStreamer</h1>

<p align="center">
  Стрим игр с Мака в браузер друга через Tailscale — с мышью, которая действительно работает.<br>
  <a href="README.md">English</a>
</p>

---

Маленькое приложение в строке меню для Маков на Apple Silicon. Захватывает экран и звук игры, кодирует аппаратным H.264 и отправляет по WebRTC на веб-страницу. На другой стороне открывают ссылку в Edge или Chrome и играют с клавиатурой и мышью. **Зрителю ничего ставить не нужно.**

## Зачем

С Mac mini в роли хоста мы пробовали Parsec, Sunshine + Moonlight и Steam Remote Play. Везде клавиатура работала, а **мышь не двигалась вообще** — даже на рабочем столе, при всех выданных правах. Работает `CGEvent`, в котором есть *и* новая позиция курсора, *и* сырые дельты (`kCGMouseEventDeltaX/Y`), отправленный в HID-tap. На этом GameStreamer и построен.

## Что умеет

- Захват экрана через ScreenCaptureKit, 60 или 120 fps, **аппаратный H.264** (VideoToolbox, режим низкой задержки, без B-кадров).
- **WebRTC** на [Pion](https://github.com/pion/webrtc): равномерная отправка, перезапросы потерянных пакетов, ключевые кадры по запросу.
- **Минимальная задержка в браузере**: кадры помечены `playout-delay = 0`, браузер показывает каждый кадр сразу после декодирования.
- **Клавиатура и мышь** по DataChannel: движение — без гарантии доставки, клики и клавиши — надёжно. Клавиши по физическому положению, Ctrl → Control, Alt → Option.
- **Два режима мыши**: *меню* (абсолютная позиция, свой курсор зрителя без задержки) и *камера* (Pointer Lock + дельты, камера крутится без упора). Нативные игры Mac, которые захватывают курсор, переключают режим сами.
- **Только звук игры**: отдельный захват звука без Discord, мессенджеров и уведомлений, Opus по 10 мс, проигрывание через WebCodecs + Web Audio.
- **Встроенный замер задержки** в статистике: Мак / сеть / браузер.
- **Меню в строке меню**: PIN, битрейт, частота кадров, источник звука, статус разрешений, автозапуск.
- **Удалённая диагностика**: браузер зрителя шлёт свою статистику в лог хоста.

## Задержка

Встроенный замер, от захвата кадра на Маке до показа в браузере (Mac mini M4, 1080p60, локально, без сети): было **43 мс**, стало **27–28 мс** (p95 33–39). Через интернет прибавьте задержку сети в одну сторону (у Tailscale с прямым соединением обычно 5–20 мс).

## Установка

1. Скачайте `GameStreamer-*.zip` из [Releases](https://github.com/defcatcher/gamestreamer/releases/latest), распакуйте, перенесите **GameStreamer.app** в **Программы**.
2. Приложение подписано самоподписанным сертификатом и **не нотаризовано**, поэтому первый запуск заблокируется. Откройте его один раз, затем **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**. Или:
   ```bash
   xattr -dr com.apple.quarantine /Applications/GameStreamer.app
   ```
3. Выдайте два разрешения: **Запись экрана и системного звука** и **Универсальный доступ** (в новых macOS — *Device Control*). В меню иконки видно ✓/✗.
4. Включите HTTPS для страницы (нужно, чтобы Esc и Alt+Tab уходили в игру):
   ```bash
   tailscale serve --bg --https=443 http://127.0.0.1:8765
   ```
   В первый раз Tailscale попросит включить HTTPS в админке tailnet. Имя Мака попадёт в публичные логи сертификатов.

## Использование

1. Запустите GameStreamer (иконка геймпада в строке меню). По желанию — «Запускать при входе в систему».
2. Отправьте зрителю `https://<ваш-мак>.<tailnet>.ts.net` и 6-значный **PIN** из меню.
3. Он открывает ссылку в Edge/Chrome, вводит PIN и играет.

| Сочетание (у зрителя) | Действие |
|---|---|
| **Ctrl+Alt+M** | мышь: *меню* ↔ *камера* (камера — для игр от первого/третьего лица) |
| **Ctrl+Alt+F** | полный экран |
| **Ctrl+Alt+S** | статистика: задержка, fps, битрейт, декодер, потери |

Мак должен быть **разблокирован**: на экране блокировки ни захват, ни ввод не работают.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| Чёрный экран, но пакеты идут | Обычно это Chrome без аппаратного декодирования. Откройте в **Edge** или включите в Chrome «Использовать аппаратное ускорение». |
| Нет звука | Нажмите красную кнопку «Браузер выключил звук». Проверьте, что на Маке что-то играет и режим звука подходит. |
| Камера упирается в край экрана | Режим *камера*: **Ctrl+Alt+M**. |
| Остальное | Меню → «Показать лог» (`~/Library/Logs/GameStreamer/host.log`). Страница с `?diag` добавляет самопроверку декодера. |

## Безопасность

Доступ защищён 6-значным PIN (5 ошибок — блокировка на 60 с), сервер слушает только localhost и адрес Tailscale. **Не открывайте его в интернет напрямую**: кто войдёт, тот управляет клавиатурой и мышью вашего Мака.

## Сборка из исходников

```bash
./scripts/make-cert.sh          # один раз: локальный сертификат подписи в .signing/
./scripts/build.sh --install    # собрать, положить в «Программы», перезапустить
```

Нужны Command Line Tools и Go 1.27+.
